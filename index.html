3.3 BrightLocal Local Search Grid
0 / 4

Create one campaign per GBP location. If the firm has five GBPs, create five campaigns. Go to BrightLocal > Local Search Grid > Create Campaign. Set grid size: metro PI markets use 7x7 or 9x9 at 0.5-1 mile; regional or rural, widen the interval. Enter 3-5 primary keywords per campaign. Scans typically take 30-60 minutes.

Default PI/MVA keywords: injury lawyer near me • personal injury lawyers • car accident lawyers • personal injury attorneys • car accident attorneys. Add practice-area-specific terms if applicable.
